# A "nacho" object with 48 samples from the GSE74821 dataset

The 48 samples come from four cartridges, normalised with the `"GLM"`
method.

## Usage

``` r
GSE74821
```

## Format

A \[[list](https://rdrr.io/r/base/list.html)\] object of class
`"nacho"`.

## Source

[GSE74821](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE74821)

## Details

NanoString nCounter RUO-PAM50 Gene Expression Custom CodeSet
